# ProyectoLumi3D
Proyecto con gestion de colas y base de datos con arbol b+ 
═══════════════════════════════════════════════════════════════
  LUMI 3D - SISTEMA DE COLAS - PC1
═══════════════════════════════════════════════════════════════

ARCHIVOS:
  PC1.jar             - App ejecutable (Java 8+)
  config.properties      - IP del servidor (editar si hace falta)
  EJECUTAR_PC1.bat    - Lanzador (doble click)

═══════════════════════════════════════════════════════════════
  CARACTERISTICAS NUEVAS
═══════════════════════════════════════════════════════════════

> RECONEXION AUTOMATICA: si el servidor se cae, los clientes
  reconectan solos hasta que vuelva a estar disponible.

> AUTO-COMPLETAR DPI: al asignar un cliente, si el DPI ya existe
  el sistema autocompleta nombre/apellido en pantalla.

> BUSQUEDA DETALLADA: muestra cantidad de lamparas, desglose por
  tipo (basico/temporada/personalizado), tiempo de atencion y
  total Q gastado por el cliente.
